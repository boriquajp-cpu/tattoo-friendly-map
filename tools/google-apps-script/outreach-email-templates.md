# 施設向けアンケート 送付メール文面

`facility-survey-form.gs.js` で生成したGoogleフォームのURLを `[フォームURL]` の箇所に貼り付けてから送信する。
件名・本文中の `【施設名】` は送付先ごとに置き換える（Gmailの「差し込み」機能、または手動コピペで対応）。

対象は2グループ・計35件（`/private/tmp/.../scratchpad/email_results_all.json` の email非nullが16件、
`new_facilities_with_email.json` が19件）。グループによって文面の導入部分だけ変えている。

---

## テンプレートA: 既にTattoo Map Japanに掲載中の施設（16件）

対象: サイト内にタトゥーに関する記述がなく、施設側の公式見解が不明なまま掲載している施設。

**件名**: 【ご協力のお願い】タトゥーのあるお客様のご案内について（Tattoo Map Japan）

```
【施設名】 ご担当者様

突然のご連絡失礼いたします。
私どもは「Tattoo Map Japan」というウェブサービスを運営しており、
タトゥー（刺青）のある方が日本国内で安心して利用できる温泉・銭湯・ジム・プール等の
施設情報を、台湾をはじめとする海外の旅行者向けにご紹介しております。

貴施設については現在、当サービスの施設情報として掲載させていただいておりますが、
タトゥーのあるお客様へのご案内方針（ご利用可否や条件）について、
貴施設の公式な情報を確認できておりません。

つきましては、正確な情報をお客様にお伝えするため、
簡単なアンケートにご協力いただけますと大変ありがたく存じます。
所要時間は1〜2分程度です。

▼ アンケートはこちら
[フォームURL]

ご回答いただいた内容は、弊社担当者が内容を確認したうえで掲載いたします
（ご回答内容がそのまま自動公開されることはございません）。
また、掲載を希望されない場合はアンケート内でその旨をお選びいただければ、
情報の掲載を行わない、または既存の掲載を取り下げさせていただきます。

ご多忙のところ恐れ入りますが、何卒よろしくお願い申し上げます。

Tattoo Map Japan 運営事務局
https://tattoo-friendly-map-lemon.vercel.app/
```
